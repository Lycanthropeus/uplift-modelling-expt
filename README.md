# Uplift Modelling experimentation

A repository that tracks how uplift modelling can help distinguish between four kinds of shoppers:
- Sure things (Customers who will make purchases irrespective of being given an offer)
- Persuadables (Customers who will make purchases **only** because they were given an offer)
- Lost causes (Customers who won't make purchases irrespective of whether they were given an offer)
- Sleeping dogs (Customers who won't make purchases **because** they were given an offer
